# Commodity Option Valuator Pro

商品期权智能估值分析系统

## 功能

- Black-Scholes 定价
- Greeks计算
- 二阶Taylor估值
- 文华财经DDE读取
- 风险评分
- 开仓建议
- 盈亏曲线
- Greeks曲线
- Excel分析报告

## 技术栈

Python 3.12

CustomTkinter

Matplotlib

Pandas

NumPy

SciPy

OpenPyXL
